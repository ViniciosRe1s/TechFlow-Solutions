# Agile Task Manager

## Objetivo
Este projeto simula o desenvolvimento de um sistema de gerenciamento de tarefas para uma startup de logística. O sistema permite criar, visualizar, atualizar e excluir tarefas, auxiliando no acompanhamento do fluxo de trabalho em metodologias ágeis.

## Escopo
O sistema possui funcionalidades básicas de CRUD para gerenciamento de tarefas.

Funcionalidades:
- Criar tarefa
- Listar tarefas
- Atualizar tarefa
- Excluir tarefa

## Metodologia
O projeto utiliza conceitos de metodologias ágeis:

- Kanban para gestão de tarefas
- Integração contínua com GitHub Actions
- Testes automatizados

## Tecnologias Utilizadas

- Python
- Flask
- PyTest
- GitHub Actions
